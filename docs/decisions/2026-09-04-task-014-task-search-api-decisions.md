# Решения реализации: задача 014

Дата: 2026-09-04
Статус: реализовано

## Граница API

- Серверный поиск доступен через `POST /api/tasks/search` с JSON-телом.
- Пустое тело-объект означает отсутствие фильтров, первую страницу размером 50 и сортировку по
  крайнему сроку по возрастанию.
- Идентификатор пользователя не принимается от клиента. Маршрут повторно проверяет текущую
  Bitrix-идентичность, требует `app_access` и создаёт адаптер с `userId` из подписанной сессии.
- Ответы не кэшируются и зависят от cookie. Ошибки и повреждённые ответы адаптера преобразуются в
  безопасные API-ошибки без внешних диагностических данных.

## Состав результата

Каждая строка содержит только данные списка: идентификатор, название, ссылку, родительскую задачу,
статус, ответственного, крайний срок, приоритет и `relevantVersion`. Контрольная версия является
хешем изменяемого состояния и нативной редактируемости задачи для текущего пользователя.

Завершённые задачи, шаблоны и правила повторения исключаются адаптером до пагинации. Подзадачи и
экземпляры повторяющихся задач не выделяются в отдельные типы и участвуют в обычной выборке.

## Сортировка и пагинация

- Nullable-значения располагаются после заданных значений при обоих направлениях сортировки.
- Поля даты и времени сравниваются как моменты времени, а не как строки с часовыми поясами.
- При равенстве основного поля используется возрастающий точный числовой идентификатор задачи без
  преобразования в небезопасный JavaScript `number`.
- Страничная пагинация не создаёт дублей при неизменном наборе результатов. Изменение задач между
  запросами страниц требует нового поиска; снимок набора и сохранённые фильтры не входят в задачу
  014.

## Валидация фильтров

Операторы наличия не принимают `values`; односторонние сравнения принимают ровно одно значение;
`between` принимает ровно две границы. Операторы выбора принимают от одного до 50 значений и
объединяют их через `ИЛИ`. Для одиночного поля `equals` означает совпадение с любым выбранным
значением; для множественного поля — равенство всего набора. `not_equals` является отрицанием этой
проверки. Некорректная семантика отклоняется после проверки сессии и доступа, но до поискового
обращения к Bitrix24.
