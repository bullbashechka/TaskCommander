# Решения задачи 018: вычисление изменений

## Граница слоя

- Калькулятор является чистой функцией. Он получает снимок задачи, проверенные команды,
  актуальный каталог доступных изменений и, для относительных дат, явный снимок календаря.
- Чтение Bitrix24, проверка доступа и редактируемости конкретной задачи, классификация
  `eligible`/`excluded`/`no_change`, межполевые ограничения и сохранение preflight относятся к
  задаче 019.
- Результат содержит исходные и целевые значения каждого поля, а также точный список реально
  изменившихся полей. Запись результата в задачу не выполняется.

## Значения и коллекции

- Сохранённые команды и снимок повторно проверяются на границе калькулятора. Отсутствующее поле,
  несовместимый тип, дубли в текущей коллекции и противоречащая каталогу команда дают типизированную
  ошибку без включения значений задачи в текст ошибки.
- `replace` сохраняет порядок команды, `add` сохраняет текущий порядок и дописывает только новые
  значения, `remove` сохраняет взаимный порядок оставшихся значений. `null` при операциях над
  коллекцией трактуется как пустая коллекция.
- Равенство коллекций не зависит от порядка. Строки сравниваются точно, без изменения регистра,
  Unicode-нормализации и числового преобразования идентификаторов Bitrix24.
- `clear` возвращает `null` для любого nullable-поля, разрешённого каталогом. Результат коллекционной
  операции не может превышать лимит адаптера в 256 значений.

## Даты и производственный календарь

- Абсолютная дата канонизируется в UTC ISO 8601. Семантически одинаковые моменты считаются равными
  независимо от исходного offset.
- Относительный сдвиг выполняется по гражданским датам часового пояса портала. Сохраняются часы,
  минуты, секунды и миллисекунды момента, представленного в зоне портала, а не текстовые часы
  исходной строки с произвольным offset.
- Исходная дата не считается первым днём сдвига. Для рабочих дней исключительный рабочий день имеет
  приоритет над праздником и обычным выходным.
- Календарный снимок содержит явные `fromYear` и `toYear`. Выход за покрытие отклоняется вместо
  предположения, что неизвестные даты являются рабочими. Задача 019 отвечает за загрузку достаточного
  диапазона.
- Несуществующее локальное время в DST-gap отклоняется. Для двусмысленного времени при обратном
  переходе DST детерминированно выбирается более ранний момент.
