# Подтверждённые продуктовые решения

Этот документ фиксирует решения обсуждения. Он не расширяет объём задачи 001.

## Контекст запуска и интерфейс

- Production-приложение доступно только внутри Битрикс24; прямое открытие позднее показывает объясняющий экран.
- Сохраняются маршрут, фильтры и сортировка; незавершённая массовая операция после обновления не восстанавливается.
- При недоступном API безопасные чтения повторяются автоматически, затем показывается ручной retry.
- При появлении новой версии пользователь получает уведомление и обновляет приложение вручную.
- Первый релиз русский и desktop-only; все пользовательские строки централизованы.

## Массовые операции

- Несколько вкладок разрешены для просмотра, но у пользователя только одна активная операция.
- Операция продолжает выполняться на сервере после закрытия вкладки или потери сети.
- Частичные ошибки не останавливают остальные элементы; повтор доступен только для неуспешных.
- Перед повтором система проверяет фактическое состояние объекта и не выполняет уже применённое действие повторно.
- Объекты, изменённые до исполнения, и объекты без прав пропускаются с отдельной причиной.
- Крупные выборки обрабатываются серверными пакетами с соблюдением лимитов Битрикс24.
- «Остановить обработку» прекращает только ещё не начатые элементы и не откатывает выполненные.
- При отзыве доступа прекращаются ещё не начатые элементы.

## Выбор, подтверждение и результаты

- История операций сохраняется полностью: параметры, инициатор, время, результаты, ошибки и остановка.
- Пользователь видит только свою историю; администратор Task Commander — всю.
- Перед запуском показывается итоговый экран; усиленное подтверждение требуется для необратимых действий и от 100 объектов.
- Завершение операции отправляет одно нативное уведомление Битрикс24; детали доступны в истории.
- При подтверждении фиксируется точный список объектов. Можно выбрать текущую страницу или все `N` результатов фильтра.
- Выбор сохраняется при смене фильтров и страниц; интерфейс постоянно показывает число выбранных объектов и очистку.
