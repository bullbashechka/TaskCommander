# Удаленная разработка с Supabase

Этот режим применяется к авторизованному удаленному Supabase-проекту. Docker не требуется.

1. Проверьте выбранный проект через Supabase MCP.
2. Прочитайте историю удаленных миграций.
3. Примените только отсутствующие forward-миграции из `supabase/migrations/`.
4. Проверьте развернутую схему и RLS-политики через MCP.
5. Отмечайте задачу в `TASKS.md` только после успешных шагов 1–4.

Не передавайте строку подключения PostgreSQL, пароль, OAuth-токен или service-role key в команды, документацию или репозиторий. В этом режиме запрещены `supabase db reset`, seed, down-миграции и pgTAP-тесты: они допустимы только в опциональном локальном Docker-контуре.
