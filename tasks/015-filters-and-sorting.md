# 015. Реализовать фильтры, сортировку и личные наборы

**Этап:** 4. Поиск, выбор и подготовка массовой операции

## Цель

Дать пользователю полный набор применимых фильтров Битрикс24 и личные сохранённые представления.

## Контекст продукта

Операторы зависят от типа поля; разные поля соединяются `И`, несколько значений одного поля — `ИЛИ`.

## Объём

- Реализовать динамический конструктор фильтров по схеме полей.
- Поддержать операторы текста, дат, чисел, списков, пользователей и boolean.
- Добавить одноуровневую сортировку и серверное применение условий.
- Реализовать создание, переименование, применение и удаление личных фильтров.

## Вне объёма

Общие фильтры и сохранённые шаблоны массовых изменений.

## Требования

- Для участников существуют отдельные условия постановщика, исполнителя, соисполнителей и наблюдателей.
- Сохранённый фильтр недоступен другому пользователю.

## Критерии приёмки

- Каждый тип поля показывает только разрешённые PRD операторы.
- Комбинации `И`/`ИЛИ` дают ожидаемую серверную выборку.
- Сортировка меняется между возрастанием и убыванием по одному полю.
- CRUD личного фильтра сохраняется между сессиями и защищён владельцем.
