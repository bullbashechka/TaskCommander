# 010. Реализовать вычисление и проверку эффективных прав

**Этап:** 3. Идентификация, права и управление доступом

## Цель

Применять пересечение штатных прав Битрикс24, прав Task Commander и персонального перечня полей.

## Контекст продукта

Права приложения только ограничивают доступ и никогда не расширяют права портала.

## Объём

- Реализовать все десять прав Task Commander из PRD.
- Вычислять эффективные права на экран, операцию, отчёт и поле.
- Автоматически давать администраторам полный доступ ко всем полям.
- Добавить серверные guards для каждого защищённого endpoint.

## Вне объёма

Экран назначения прав и автоматический отзыв.

## Требования

- Клиентские ограничения не заменяют серверную проверку.
- Для чужого повтора/восстановления проверяются просмотр всех отчётов и право действия.

## Критерии приёмки

- Пользователь без права не может вызвать защищённый API напрямую.
- Разрешённое поле недоступно, если штатные права запрещают изменение конкретной задачи.
- Администратор всегда получает полный набор и не может быть ограничен настройками Task Commander.
- Матрица ролей и прав покрыта автоматическими тестами.
