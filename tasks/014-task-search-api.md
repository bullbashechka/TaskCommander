# 014. Реализовать серверный поиск незавершённых задач

**Этап:** 4. Поиск, выбор и подготовка массовой операции

## Цель

Получать только доступные текущему пользователю незавершённые задачи и подзадачи.

## Контекст продукта

Завершённые задачи, шаблоны и правила повторения полностью исключены из рабочего набора.

## Объём

- Реализовать adapter/API для серверного поиска, сортировки и пагинации.
- Применять штатные права текущего пользователя при запросе.
- Поддержать обычные задачи, подзадачи и повторяющиеся экземпляры как обычные задачи.
- Возвращать минимальные данные для списка и контрольную версию.

## Вне объёма

Сохранённые фильтры и изменение задач.

## Требования

- Task Commander не расширяет выборку сверх нативного доступа.
- По умолчанию сортировка идёт по крайнему сроку по возрастанию.

## Критерии приёмки

- Завершённая, недоступная задача и шаблон не появляются ни в одном ответе.
- Подзадачи и незавершённые повторяющиеся экземпляры доступны как обычные задачи.
- Ответ содержит общее количество и устойчивую пагинацию без дублей.
- Тесты подтверждают соблюдение доступа для разных пользователей.
