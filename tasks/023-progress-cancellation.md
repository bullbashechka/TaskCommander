# 023. Реализовать прогресс, отмену и прерывание операции

**Этап:** 5. Выполнение, повтор и восстановление

## Цель

Показывать достоверное состояние выполнения и корректно останавливать запуск новых задач.

## Контекст продукта

После отмены, серверного сбоя или отзыва прав завершается текущая задача и формируется частичный результат. Закрытие браузера и потеря пользовательской сети не останавливают серверную операцию.

## Объём

- Реализовать endpoint/подписку прогресса и экран выполнения.
- Показать все счётчики и процент из PRD.
- Добавить явную отмену и предупреждение, что операция продолжится после закрытия приложения.
- Реализовать server-side heartbeat/lease consumer-а для выявления зависшего обработчика, без client heartbeat.
- Передавать `stateVersion` в каждом ответе прогресса и игнорировать в UI устаревшие ответы.
- Отметить оставшиеся задачи как `Не обработана`.

## Вне объёма

Автоматическое возобновление остановленной операции.

## Требования

- После сигнала остановки новая задача не начинается.
- Процент показывает долю задач с зафиксированным результатом, а не долю успешных изменений.
- Повторное открытие приложения показывает актуальный прогресс или итог и не создаёт повторную операцию.

## Критерии приёмки

- Счётчики UI совпадают с сохранёнными результатами.
- Отмена завершает текущую задачу и переводит операцию в `Отменена`.
- Потеря lease или прав переводит операцию в `Прервана`.
- Для обоих конечных состояний доступны обработанные и необработанные задачи.

## Зависимости

012, 022.

## Реализация и проверка

Реализованы серверный прогресс и ограниченная выдача результатов задач, отмена с проверкой владельца и актуальных прав, lease/heartbeat и watchdog, экран выполнения с восстановлением после повторного открытия. Обработаны устаревшие ответы при переключении операций и потеря доступа. Независимое ревью: backend 9/10, UI 8/10; последние замечания UI исправлены после оценки.

Проверки выполняет пользователь: `bun run check`, `bun run db:docker:test`. Реальный портал Bitrix24 недоступен, интеграционный smoke-тест остаётся открытым.
