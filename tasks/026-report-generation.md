# 026. Формировать XLSX- и CSV-отчёты

**Этап:** 6. Отчёты, история и эксплуатационные процессы

## Цель

Создавать оба формата отчёта для любого конечного состояния операции.

## Контекст продукта

Отчёт содержит результаты по задачам, но не содержит защищённые предыдущие значения.

## Объём

- Сформировать единый табличный dataset из результатов операции.
- Генерировать XLSX и CSV независимо друг от друга.
- Временно сохранять файлы в R2.
- Записать метаданные и статус формирования каждого формата.
- При позднем уточнении результата сформировать новую версию отчёта, не заменяя исходный файл.

## Вне объёма

Загрузка на Диск и UI истории.

## Требования

- Отчёт создаётся для `Завершена`, `Завершена с ошибками`, `Отменена` и `Прервана`.
- Ошибка одного формата не блокирует другой и фиксируется в аудите.

## Критерии приёмки

- Каждая строка содержит ID, название, ссылку, поля, результат и понятную ошибку/конфликт.
- XLSX открывается табличным редактором, CSV имеет зафиксированные UTF-8 и разделитель.
- Предыдущие значения, токены и secrets отсутствуют в файлах.
- Частичный отчёт содержит обработанные и необработанные задачи.
