# 008. Реализовать машину состояний и идемпотентность операций

**Этап:** 2. Данные и серверные инварианты

## Цель

Исключить дубли и недопустимые переходы массовой операции.

## Контекст продукта

Повторный клик, обновление страницы или повторная доставка запроса не должны создавать вторую операцию; частичный сбой сохраняет уже полученные результаты.

## Объём

- Реализовать допустимые переходы всех статусов операции из PRD.
- Ввести идемпотентный ключ создания и обработки.
- Обеспечить ограничение одной активной операции на пользователя.
- Атомарно пересчитывать итоговые счётчики по результатам задач.

## Вне объёма

Очередь и фактическое изменение задач.

## Требования

- Разные пользователи могут иметь активные операции одновременно.
- Конечный статус вычисляется из сохранённых результатов, отмены и причины прерывания.

## Критерии приёмки

- Повтор одинакового запроса возвращает ту же операцию.
- База отклоняет вторую активную операцию одного пользователя.
- Недопустимый переход статуса не записывается и фиксируется как системная ошибка.
- Тесты покрывают завершение, ошибки, отмену, прерывание и частичный результат.
