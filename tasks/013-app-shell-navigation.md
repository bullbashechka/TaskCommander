# 013. Создать оболочку приложения и навигацию по правам

**Этап:** 4. Поиск, выбор и подготовка массовой операции

## Цель

Создать русскоязычную desktop-оболочку встроенного приложения с доступными пользователю разделами.

## Контекст продукта

Основные разделы: массовое изменение, история/архив, управление доступом и аудит.

## Объём

- Реализовать TanStack Router, общую шапку, навигацию и обработку сессии.
- Скрывать и блокировать маршруты по эффективным правам.
- Добавить состояния загрузки, пустых данных, ошибок и потери соединения.
- Соблюсти структуру и состояния из `design.md`.

## Вне объёма

Мобильная адаптация и другие локализации.

## Требования

- Интерфейс работает внутри iframe/контекста веб-версии Битрикс24.
- Все длительные действия имеют видимый статус.

## Критерии приёмки

- Пользователь видит только разрешённые разделы и не открывает закрытый route напрямую.
- Ошибка сессии переводит в безопасное состояние без показа продуктовых данных.
- Навигация работает с клавиатуры и сохраняет логичный focus.
- Все пользовательские строки первой версии отображаются на русском языке.
