# 019. Реализовать предварительную проверку задач

**Этап:** 4. Поиск, выбор и подготовка массовой операции

## Цель

Перед подтверждением повторно проверить каждую выбранную задачу и исключить небезопасные изменения.

## Контекст продукта

Ошибка одной задачи не блокирует остальные; операция невозможна, если не прошла ни одна задача.

## Объём

- Повторно получить актуальные данные всех выбранных задач.
- Проверить существование, статус, доступ, право задачи/поля, значения, связанные данные и ограничения Битрикс24.
- Рассчитать старые/новые значения и контрольную версию.
- Сохранить причины исключения по каждой задаче.

## Вне объёма

Подтверждение и изменение задач.

## Требования

- Результат проверки привязан к пользователю, выбору и параметрам изменений.
- Изменение параметров инвалидирует результат проверки.

## Критерии приёмки

- Каждая задача получает результат `допущена` или `Исключена проверкой` с причиной.
- Частичная ошибка сохраняет допустимый набор для продолжения.
- Нулевой допустимый набор блокирует запуск.
- Прямой вызов API не позволяет обойти проверку прав и значений.

## Зависимости
