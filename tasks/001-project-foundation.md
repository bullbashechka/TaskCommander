# 001. Инициализировать структуру проекта и базовые проверки

**Этап:** 1. Основа проекта и локальный контур

## Цель

Подготовить воспроизводимую структуру `webapp` и `backend` на утверждённом стеке.

## Контекст продукта

Task Commander встраивается в веб-версию Битрикс24; клиент работает на React/Vite/TypeScript, API и BFF — на Hono в Cloudflare Workers.

## Объём

- Адаптировать основу репозитория под активные поверхности `webapp` и `backend`.
- Настроить TypeScript, линтинг, форматирование, typecheck и тестовые команды.
- Подключить TanStack Router/Query/Table/Form, Tailwind CSS v4, Base UI, shadcn/ui и Sonner.
- Зафиксировать команды локального запуска и проверки.

## Вне объёма

Production-деплой, OAuth Битрикс24 и бизнес-функции массовой операции.

## Требования

- Использовать Bun как package manager и локальный runtime; не использовать pnpm, Prisma, Supabase Auth, Storage или Edge Functions.
- Не настраивать и не валидировать `website` и `mobile` как часть первой версии.

## Критерии приёмки

- Чистая установка зависимостей завершается без ручных исправлений.
- `webapp` и локальный Worker запускаются одной документированной последовательностью команд.
- Typecheck, линтер и минимальные тесты проходят локально. CI не входит в задачу 001.
- Клиент получает тестовый ответ от локального Hono API.

## Зависимости

Нет.

## Примечания по реализации

Workers должны обслуживать API и собранные статические assets webapp.
