# 017. Реализовать настройку разрешённых массовых изменений

**Этап:** 4. Поиск, выбор и подготовка массовой операции

## Цель

Позволить задать одно или несколько изменений только для разрешённых и поддерживаемых полей.

## Контекст продукта

Обязательный набор включает название, описание, участников, даты, приоритет, незавершённые статусы, проект/группу и теги.

## Объём

- Получать редактируемую схему полей из Bitrix24 adapter.
- Пересекать её с правами пользователя и персональным allowlist.
- Реализовать форму нескольких полей через TanStack Form.
- Исключить завершение, удаление, комментарии, файлы, чек-листы, шаблоны, повторения и создание задач.

## Вне объёма

Фактическое применение значений к задачам.

## Требования

- Статус `Завершена` и поля вложений недоступны.
- Изменение состава полей сбрасывает ранее выданное подтверждение.

## Критерии приёмки

- Пользователь видит только пересечение API-возможностей и своего allowlist.
- Форма поддерживает несколько полей в одной операции.
- Запрещённые действия отсутствуют в UI и отклоняются API.
- Схема формы корректно обновляется при изменении effective permissions.

## Зависимости
