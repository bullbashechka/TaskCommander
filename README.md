# Task Commander

Локальная основа веб-приложения Task Commander для Битрикс24.

## Требования

- Bun 1.3.14 или новее.

Если PowerShell блокирует `bun.ps1` политикой выполнения сценариев, используйте `bun.cmd` в тех же командах, например `bun.cmd run dev`.

## Локальный запуск

```powershell
bun install --frozen-lockfile
bun run dev
```

Откройте адрес, который выведет Vite. Приложение и Hono API работают на одном origin. Стартовая страница подтверждает ответ `GET /api/health`.

## Проверки

```powershell
bun run check
bun run build
bun run preview
```

`bun run check` запускает форматирование без записи, линтер, TypeScript и тесты. CI намеренно отсутствует в задаче 001.

После `bun run preview` проверьте:

- `/api/health` возвращает JSON;
- `/status?panel=api` открывается напрямую и после обновления страницы;
- экран показывает состояние API на русском языке.

## Границы первого этапа

Production-развёртывание, OAuth, контекст Битрикс24 и бизнес-функции массовых операций пока не реализованы. Production-версия в дальнейшем будет доступна только внутри Битрикс24; локальный контур существует для разработки.
